You can run this workshop in your own AWS account or use a temporary AWS account provisioned by the workshop instructor. Refer to either of the following sections for detailed instructions.

1. [At an AWS workshop event](/01-prerequisites/1-workshop/): If you are running the workshop as part of an AWS event, all the necessary configuration is already done for you in the provided workshop AWS account.
2. [Your own AWS account](/01-prerequisites/2-account/): Follow this section to set up and configure your own AWS account to run this workshop. Skip it if you are participating in an AWS event.
3. [SageMaker AI Studio](/01-prerequisites/3-sagemaker/): The environment where you will run the workshop notebooks. Required in both cases.

Now, choose one of the options above to get started!
